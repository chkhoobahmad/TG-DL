## 📖 How to use

### For ZIP Archive Exports:
1. Download all parts of the zip file
2. Extract the first part (.zip) to get the complete folder
3. Open `index.html` in your browser to browse messages

### For Normal Folder Exports:
1. Navigate into the channel folder
2. Open `index.html` in your browser to browse messages
3. Each message has its own folder with text and media files
4. Files larger than 45MB are automatically split into parts
